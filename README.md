# 336-twin-bell-shooter
Unity制作2日目（Day102）：縦シューティング Twin Bell Shooter（オリジナル機体「スワロー」／画面下30%のオリジナル・コントローラー）

- エンジン：Unity 6000.3.26f1（Built-in描画・2Dスプライトをコードで生成）
- 操作：十字キー（移動）／A（連射・長押しでため→バズーカ）／B（ため）／SELECT（画面揺れ 強・弱・OFF）／START（一時停止・リトライ）。ゲーム画面をなぞると指の移動量だけ移動＋自動連射
- PC：WASD/矢印、Z/J＝A、X/K＝B、C＝SELECT、Enter/Esc＝START
- 開き方：Unity Hub →「Add project from disk」でこのフォルダ → `Assets/Scenes/TbShooter.unity` を開いて Play
- ビルド／公開の手順：[docs/RELEASE.md](docs/RELEASE.md)
- 同じプロジェクトに前日のランナー試作（Day102Bootstrap など）が残っています（削除していません）
